# python_programs

A collection of small, self-contained Python programs, from beginner exercises
to simple automation scripts. They use only the standard library and need Python 3.9 or newer.

## Running

Every file runs on its own and prints a short demonstration:

```bash
python 01_basics/fibonacci.py
```

Run the tests from the repository root:

```bash
python -m unittest discover tests
```

## Contents

| Folder | Programs |

| [03_collections](03_collections) | list operations, dictionary operations, stack and queue, matrix operations |
| [04_algorithms](04_algorithms) | linear and binary search, five sorting algorithms, recursion examples |
